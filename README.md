# Spotify Music Player

A lightweight, browser-based music player interface designed to replicate core media playback functionality. This project serves as a frontend application, featuring a clean layout with built-in audio controls for immediate track playback.

## 🔗 Live Demo
Check out the live version of the project here: [Spotify Music Player](https://koparth-exe.github.io/Spotify-Music-Player/)

## ✨ Features
* **Native Audio Playback:** Utilizes HTML5 `<audio>` tags for seamless, out-of-the-box music playback without external dependencies[cite: 3].
* **Straightforward UI:** Features a classic header navigation alongside a grid of accessible song cards[cite: 3].
* **Curated Tracklist:** Includes a built-in playlist of tracks (including "Close to the sun," "Malang Sajna," and more) ready to play[cite: 3].

## 🛠️ Tech Stack
* **HTML5:** For structuring the web application and embedding native media controls[cite: 3].
* **CSS3:** For styling the layout, navigation bar, and tracklist containers[cite: 3].

## 🚀 Future Enhancements
* Transition the user interface to a terminal-inspired dark mode aesthetic.
* Implement JavaScript for dynamic state management, such as continuous playback, global volume controls, and a unified track scrubber.
* Integrate the official Spotify Web API to fetch dynamic user playlists and real-time song data.
